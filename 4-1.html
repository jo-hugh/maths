🏦 4.1 單利息（Simple Interest）

本金（Principal）$P，年利率（Annual interest rate）R%（R 厘），存款年期 T 年：

單利息 I = P × R% × T　　本利和（Amount）A = P + I = P + P × R% × T
📌 「厘」即 %：2 厘 = 2%，2 厘半 = 2.5% = 0.025，5 厘 = 5%。
📌 T 必須用「年」：18 個月 → T = 1.5；9 個月 → T = 0.75；1 季 = 3 個月 → T = 0.25。

🗣 提問：$10,000 存 1 年，年利率 3 厘，利息多少？

例 4.01　求單利息

$60,000 存入銀行，年利率 2.5%，以單利息計算，求以下年期的利息：(a) 4 年　(b) 3 個月　(c) 18 個月

(a) $　(b) $　(c) $

(a) I = 60,000 × 2.5% × 4 = $6,000
(b) 3 個月 = 0.25 年：I = 60,000 × 2.5% × 0.25 = $375
(c) 18 個月 = 1.5 年：I = 60,000 × 2.5% × 1.5 = $2,250

例 4.02　反求本金／利率

(a) 以年利率 2% 單利息存款 4 年，可得利息 $2,600，求本金。
(b) $75,000 存款 8 年，可得單利息 $21,000，求年利率。

(a) P = $　(b) r = %

(a) 設本金 $P：2,600 = P × 2% × 4 → 2,600 = 0.08P → P = 32,500
(b) 21,000 = 75,000 × r% × 8 → 21,000 = 6,000r → r = 3.5，即年利率 3.5%

$40,000 以年利率 4.8% 單利息存款 20 年，求利息。

I = $

I = 40,000 × 4.8% × 20 = $38,400（幾乎等於本金！）

⚖️ 單利息 vs 複利息：有甚麼分別？

單利息（Simple Interest）複利息（Compound Interest）
利息以甚麼計算？永遠以原本金 P 計算以上一期的本利和計算（利息會「生利息」）
每年利息固定不變：P × R%逐年增加
公式I = P × R% × T
A = P(1 + R% × T)		A = P(1 + r%/n)nt
I = A − P
增長方式📏 線性增長（直線）🚀 指數增長（向上彎的曲線）
「年期」位置T 在乘數位置t 在指數位置
結息次數 n沒有影響n 愈大，本利和愈大
何時兩者相等？存款 1 年、每年結息一次（t = 1，n = 1）時，單利息 = 複利息；之後複利息必定較多
單利息：A = P + P·R%·T（每年加相同金額）　｜　複利息：A = P × (1 + r%)ᵗ（每年乘相同倍數）

例 4.06　單利 vs 複利

$180,000 存款，年利率 5 厘，3 年。(a) 求單利息　(b) 求複利息（每年結息一次，準確至 $0.01）

(a) $　(b) $

(a) I = 180,000 × 5% × 3 = $27,000（5 厘 = 5%）
(b) I = 180,000 × (1 + 5%)³ − 180,000 = 208,372.50 − 180,000 = $28,372.50（比單利多 $1,372.50）

例 4.07　反求利率 + 改變結息次數

$18,000 存入銀行，每半年結息一次，1 年後本利和為 $19,096.2。(a) 求年利率。(b) 若改以同一年利率存款 3 年、每 3 個月結息一次，求 3 年後的本利和（準確至 $0.01）。

(a) r = %　(b) $

(a) 18,000 (1 + r%/2)² = 19,096.2 → (1 + r%/2)² = 1.0609 → 1 + r%/2 = 1.03 → r% = 0.06 → r = 6（6 厘）
(b) 每 3 個月 = 每季，n = 4，每期利率 6%/4 = 1.5%，期數 4 × 3 = 12
A = 18,000 × (1 + 1.5%)¹² = $21,521.14

例 4.08　每季結息、中途換利率 ⭐

$80,000 存入銀行，年利率 3%，每季結息一次。(a) 求 1.5 年後的本利和。(b) 若 1.5 年後年利率改為 4%，求存款 2 年所得的複利息。（準確至 $0.01）

(a) $　(b) $

(a) 期數 = 1.5 × 4 = 6；每期利率 = 3% ÷ 4 = 0.75%
A = 80,000 × (1 + 0.75%)⁶ = 80,000 × 1.0075⁶ = $83,668.18
(b) 4% 的期數 = (2 − 1.5) × 4 = 2；每期利率 = 4% ÷ 4 = 1%
A = 80,000 × 1.0075⁶ × 1.01²
I = 80,000 × 1.0075⁶ × 1.01² − 80,000 = $5,349.91
🧠 換利率時不要重新開始：把前一段的本利和繼續乘上新利率的因子即可。

例 4.09　用計算機反求利率

$70,000 存入銀行，每月結息一次，3 個月後本利和為 $70,966.92，求年利率。

r = %

70,000 (1 + r%/12)³ = 70,966.92
(1 + r%/12)³ = 1.013813…
1 + r%/12 = ∛1.013813 = 1.0045833…（計算機：Shift → ˣ√ 或 ^(1/3)，再 EXE）

例 4.10　用 log 求年期

$12,300 以年利率 5% 每年結息一次存款，要獲得利息 $1,500，最少需存款多少年？

t ≈ （準確至 2 位小數）　→ 至少需存 整年

本利和 = 12,300 + 1,500 = $13,800
12,300 (1.05)ᵗ = 13,800 → 1.05ᵗ = 1.12195…
兩邊取 log（Take log）：t log 1.05 = log 1.12195
t = log 1.12195 ÷ log 1.05 ≈ 2.36

📐 4.3 實際年利率（Effective Interest Rate, ER）

不同結息次數的計劃，單看「年利率」無法比較。把一年內實際增長換算成「每年結息一次」的利率：

ER = (1 + r%/n)n − 1　　（與本金 P 無關）

🧮 試算：年利率 %，結息 　→

例 4.11　比較兩個計劃

《計劃一》年利率 5%，每年結息一次；《計劃二》年利率 4.8%，每星期結息一次。哪個計劃利息較多？

計劃一 ER = %　計劃二 ER = %（2 位小數）

《計劃一》ER = (1 + 5%)¹ − 1 = 5%
《計劃二》ER = (1 + 4.8%/52)⁵² − 1 = 4.91%
由此可知，《計劃一》所提供的利息會較多。

📌 總結

1️⃣ 單利息：I = P × R% × T；A = P + I；T 用「年」；「厘」= %

2️⃣ 複利息：A = P(1 + r%/n)nt；每期利率 = r% ÷ n，期數 = n × t；複利息 = A − P

3️⃣ 單利 vs 複利：單利是直線（每年加相同金額），複利是曲線（每年乘相同倍數）；1 年每年結息時相等，之後複利必較多

4️⃣ n：每年 1、每半年 2、每季 4、每月 12、每星期 52、每日 365

5️⃣ 反求：求 P → 除法；求 r → 開 n 次方根；求 t → 取 log

6️⃣ 實際年利率 ER = (1 + r%/n)n − 1，用來公平比較不同結息次數的計劃
