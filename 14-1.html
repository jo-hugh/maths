⚡ 先認識代入法（Method of substitution）

已知 y = 0.2x。當 x = 30 時，y 的值是甚麼？

y = 0.2x
y = 0.2 × 30
y = 6

🚗 例子一：私家車以固定速率行駛

下表列出該汽車的行車距離（x km）和對應的耗油量（y L）。

行車距離 (x km)0510152025
耗油量 (y L)012345

耗油量 y 取決於行車距離 x，關係為 y = 0.2x。

y 是應變量（Dependent variable），x 是自變量（Independent variable）。我們稱 y 是 x 的函數，記作 y = f(x)
⛽ 若行車距離影響耗油量：行車距離是自變量 x，耗油量是因變量 y。函數就好像一台機器：輸入 x = 25 → 輸出 y = 5。

🎄 例子二：聖誕派對

一班學生籌備聖誕派對，須以 $500 租用場地，每位參加學生的用餐費用為 $80。以 x 表示參加人數、$y 表示開支：

y = f(x) = 80x + 500

當出席派對學生是 10 位時，代入 x = 10：y = f(10) = 80 × 10 + 500 = 1300

🗣 提問：(1) 哪一個是自變量？（人數 x）(2) 15 人時開支是多少？

📌 結論：在變量 x 和 y 的關係中，若每個自變量 x 值都只對應一個應變量 y 值，y = f(x) 則 y 是 x 的函數。

例 14.02　二次函數、分數代入

若 g(x) = x² + 3x − 4，求 (a) g(2)　(b) g(−½)

(a) 　(b) （可輸入分數如 −21/4）

(a) g(2) = (2)² + 3 × 2 − 4 = 4 + 6 − 4 = 6

例 14.03　代入代數式

若 f(x) = x² − 5x + 4，求 (a) f(3a)　(b) f(−2a)

(a) a² + a + 　(b) a² + a +

(a) f(3a) = (3a)² − 5 × (3a) + 4 = 9a² − 15a + 4
(b) f(−2a) = (−2a)² − 5 × (−2a) + 4 = 4a² + 10a + 4 = 2(2a² + 5a + 2)（抽因子）

例 14.07　直線與坐標軸的交點

直線方程 3x + 4y = 12 的圖像與 y 軸相交於 A 點及與 x 軸相交於 B 點。求 A 點及 B 點的坐標。

A( , )　B( , )

∵ 圖像與 y 軸相交於 A，∴ A 的 x 坐標是 0。
把 x = 0 代入：3 × 0 + 4y = 12 → 4y = 12 → y = 3　∴ A = (0, 3)
∵ 圖像與 x 軸相交於 B，∴ B 的 y 坐標是 0。
把 y = 0 代入：3x + 4 × 0 = 12 → 3x = 12 → x = 4　∴ B = (4, 0)
📌 口訣：在 y 軸上 x = 0；在 x 軸上 y = 0。

📌 總結

1️⃣ 函數 = 機器：輸入 x（自變量），輸出 y = f(x)（應變量）；每個 x 只對應一個 y

2️⃣ 求函數值三步：把 x 全部換成數值 → 加括號 → 計算（先乘方、後乘除、再加減）

3️⃣ 代數代入：(3a)² = 9a²；(w + 3)² = w² + 6w + 9；負號乘入括號每一項

4️⃣ 反求常數：把已知的 f(數) = 值 寫成方程，解出 k 或 b

5️⃣ 分式函數：分母不能為 0（x ≠ 3、x ≠ −4）

常見錯誤及應對

常見錯誤教師回應策略
f(−3) 把 (−3)² 算成 −9（例 14.01、Q8、Q15）規定「代入先寫括號」：f(−3) = (−3)² − …；用函數機器輸入 −3 示範
3ˣ 當作 3x（Q2、Q9）強調指數位置：3² = 9、3³ = 27；對比 2x² 是 2 × x²
(3a)² 寫成 3a²（例 14.03、Q12）把 (3a)² 展開為 3a × 3a = 9a²
(w + 3)² 寫成 w² + 9（例 14.04、Q10）重溫完全平方：(w + 3)(w + 3) 用分配律乘開
−2(w² + 6w + 9) 只乘第一項（例 14.04）畫箭嘴把 −2 分配到每一項
分數代入 (−½)² 得 −¼（例 14.02、Q1）負負得正；通分時統一分母（¼ − 6⁄4 − 16⁄4）
Q14 把 P(r) 當作 P(−3)分兩步：先 r = P(−3) = 9，再 P(9)；強調「輸出再放入機器」
以為 f(a) + f(b) = f(a + b)（例 14.05、Q4、Q5）用 F(x) = ⅓x² 具體計算：F(1) + F(2) = 5⁄3 ≠ F(3) = 3，函數「不可拆開」
